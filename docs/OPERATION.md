# 시연 및 운영 절차

## 시작

1. 카메라 인식 구역을 비웁니다.
2. Raspberry Pi와 서보 외부 SMPS 전원을 켭니다.
3. 카메라 배경 수집과 PIR 안정화를 기다립니다.
4. 시스템 준비 완료 메시지 이후 사람이 접근하면 `ready.wav`가 한 번 재생됩니다.

## 정상 시연 순서

1. 캔
2. 투명 페트병
3. 플라스틱 용기
4. 종이컵
5. 지원하지 않는 물체(`other`)

각 물체는 ROI 중앙에서 손으로 크게 가리지 않고 1~2초간 유지합니다.

## 기대 동작

- 캔 → 캔 음성, 채널 0 개방
- 투명 PET → 투명 페트병 음성, 채널 4 개방
- 플라스틱 → 플라스틱 음성, 채널 11 개방
- 종이 → 종이 음성, 채널 15 개방
- other → 거부 안내, 뚜껑 개방 안 함
- 동일 물체 장시간 유지 → 제거 후 재투입 안내
- 물체 제거 → 다음 인식 대기

## 종료

```bash
sudo systemctl stop smart-bin.service
sudo shutdown -h now
```

파일시스템 손상을 막기 위해 전원을 직접 차단하기 전에 운영체제를 종료합니다.
